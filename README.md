# Student Attendance Management System

A web app to manage student attendance digitally using Java, HTML, CSS, JavaScript & MySQL.

## Features
- Add / Manage Students
- Daily Attendance Marking (Present / Absent)
- Admin Dashboard
- Attendance Reports
- Search Student by Roll No

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Java (JSP / Servlet)
- Database: MySQL

## How to Run
1. Clone this repo
2. Import Database in MySQL
3. Run on Apache Tomcat
4. Open localhost:8080
